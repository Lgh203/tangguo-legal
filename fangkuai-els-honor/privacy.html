连云港岑禾文化传媒有限公司（以下简称“我们”）是《方块俄罗斯大狂欢》（包名 com.tetris.elsd.honor）的运营者及个人信息处理者。我们重视您的隐私和个人信息保护。请在使用前阅读本政策，尤其是信息处理、未成年人保护和您的权利条款。未满十四周岁的用户应由监护人阅读并同意。

一、适用范围与当前服务

本政策适用于本游戏当前提供的本地方块消除玩法和相关设置。本游戏不含广告、付费购买、用户聊天或个性化推荐。当前界面准备版本尚未接入荣耀账号、实名认证、防沉迷和联运 SDK，不提供真实账号注册或登录，也不自行收集您的姓名、身份证件号码或手机号码。

后续如接入荣耀账号或平台要求的服务，我们会在启用前根据所用 SDK 的真实版本、功能、信息种类、触发时机、接收方和权限更新本政策及第三方清单，并在需要时重新取得您的同意。当前政策不代表这些服务已经启用。

二、我们如何处理信息

1. 游戏数据：当前棋盘、候选方块、模式、分数、最佳纪录、剩余时间和音效/主题设置保存在您的设备本地，用于继续游戏及保留设置；不会上传至我们的服务器。

2. 隐私选择：您主动同意后，我们在本地保存政策版本和同意时间，以记录选择。不同意不会触发账号服务或第三方 SDK 初始化。您可重新阅读政策、撤回同意。

3. 本地运行：Unity 引擎在设备上使用运行所需的屏幕、图形、系统和应用环境信息完成绘制、输入、音频和存档。当前版本未启用 Unity Analytics、广告、云存储、远程诊断或行为分析。

4. 联系客服：您主动通过电话或邮件联系我们时，通信服务商会处理必要通信信息。我们只在处理问题所需的范围内处理您提供的联系方式、问题描述和自愿提供的材料。请勿发送无关敏感信息；依法需要核验身份时，我们会说明用途并采取必要保护措施。

5. 访问在线政策：应用内提供无需联网的完整政策正文，您也可以主动在系统浏览器打开 GitHub Pages 公开网址。浏览器和网站托管方 GitHub 会按照其自身政策处理网站访问所需的 IP、请求及访问日志。我们没有为此植入广告追踪或统计脚本。

三、第三方服务及共享清单

Unity 运行时（Unity Technologies）：用于本地游戏图形、输入、音频和文件存储；当前未启用其广告、分析、云存储等联网服务。隐私说明：https://unity.com/legal/game-player-and-app-user-privacy-policy

GitHub Pages（GitHub, Inc.）：只在您主动访问在线法律页面时提供静态网页托管，可能处理网站请求、IP 地址等访问日志。网页不包含广告、第三方字体、统计或追踪脚本。隐私说明：https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement

荣耀账号/游戏联运 SDK：当前未集成、未初始化，不发生相应数据处理。集成后会在上线前更新本项，明确 SDK 名称、提供方、版本、用途、信息范围、处理方式、场景与政策链接。

我们不会出售您的个人信息，不会将本地游戏数据主动提供给第三方。法律要求披露或业务发生变化时，我们将依法履行相应告知和保护义务。

四、权限与处理时机

当前游戏不申请通讯录、定位、摄像头、麦克风、电话、相册、外部存储或读取已安装应用列表等权限，不读取传感器列表或传感器实时数值。当前应用本身不发起网络请求；在线页面由您主动打开的系统浏览器访问。

后续接入必要 SDK 前，我们会核实其权限与实际行为，遵循最小必要原则，在依法需要同意时先告知并取得同意，不通过提前初始化绕过您的选择。

五、存储期限、安全与跨境

本地游戏数据保存在应用私有目录，直至您主动清除、卸载或数据被系统删除；无需继续使用的本地数据可在游戏设置中清除。卸载可能导致进度永久丢失。同意记录仅用于保留您的隐私选择。

客服材料在完成处理和履行必要法定义务所需的期限内保留，之后删除或匿名化；我们采取合理的访问控制和保护措施。

我们不主动把本地游戏数据传输境外。GitHub Pages 属于境外托管服务，主动访问在线页面会由浏览器连接其服务；不希望访问该服务时，可使用游戏内的完整离线正文。若将来我们开展依法需要单独同意的跨境个人信息处理，将提前说明并履行相应程序。

六、您的权利与联系处理

您可通过游戏内“隐私与服务”重新阅读政策、撤回同意或清除本地游戏数据。撤回后将停止游戏服务并回到隐私确认页；撤回不影响此前基于同意进行处理的效力。清除数据是单独操作，撤回同意不会偷偷删除您的游戏进度。

您依法享有查阅、复制、更正、补充、删除个人信息，撤回同意及提出解释说明请求等权利。当前无自建账号，因此不存在本游戏账号注销；如以后接入平台账号，将说明退出登录、解除授权及注销申请渠道。我们不会代您注销整个荣耀账号。

您可通过下方电话或邮箱提出请求。我们将在收到请求后十五个工作日内答复；必要时会在最小范围内核实身份，并依法处理。您对处理结果有异议时，可向有权机关投诉或依法寻求救济。

七、未成年人保护

本游戏提供 8+ 适龄提示，该提示不是实名认证结果，也不代替平台年龄认证和防沉迷措施。未成年人应在监护人指导下使用，合理安排时间。未满十四周岁用户的个人信息属于敏感个人信息，涉及相应处理时应依法取得监护人同意并采取专门保护。

监护人可联系我们查询、更正或删除未成年人的相关信息。当前版本不收集实名认证资料；后续相关平台能力接入后，以真实接入流程及更新后的政策为准。

八、政策变更

我们可能因功能或法律要求更新本政策。重大变更将在游戏内显著提示；依法需要重新同意时，在同意前不会启用相应处理。在线正文与游戏内正文将同步更新并标注版本。
