一、服务与处理原则

本游戏提供本地方块消除玩法，接入荣耀游戏联运 SDK 2.0.28.301，用于荣耀账号登录、平台协议、实名认证/防沉迷、必要服务更新、角色积分上报及游戏退出引导。不提供广告、充值、道具购买、用户聊天或个性化推荐。

首次使用由我们先展示本政策和用户协议。未同意时不调用荣耀 SDK 初始化或账号登录；同意后由您点击荣耀账号登录，启动平台必要服务。我们不请求头像、昵称等可选资料授权，不要求您把荣耀密码或验证码交给我们。账号授权遵循最小必要原则；平台依法要求的实名、防沉迷流程不等同于额外头像昵称权限。

二、处理的信息、用途与时机

1. 本地游戏数据：棋盘、候选方块、模式、分数、最佳纪录、剩余时间、主题和声音设置保存在设备私有目录，用于继续游戏和保留设置。清除数据或卸载可能导致进度丢失。登录成功及分数/模式变化时，按平台接口上报角色标识、固定游戏角色名、区服、模式和分数，用于平台游戏服务；本游戏没有独立角色成长系统，不上传虚构等级或充值记录。

2. 隐私选择：保存您同意的政策版本与时间，用于记住隐私选择和版本更新提醒。游戏内可重新阅读、撤回或清除本地数据。

3. 荣耀账号：在您同意并发起登录后，SDK 处理账号 Open ID、认证令牌和认证结果，实现授权登录、身份识别和安全保障。平台流程可能包含账号切换、平台协议和账号服务更新；我们仅在真实 SDK 返回有效登录结果后开放游戏入口，不在设备存储账号密码或令牌，不打印完整账号响应。

4. 实名认证/防沉迷：由平台必要流程处理您主动提交的姓名、身份证件号码及认证/年龄结果，用于身份核验、年龄判断和防沉迷。请在平台官方界面操作；我们不设置自己的姓名和身份证输入框。未成年人应遵守平台时段限制，收到平台退出要求时游戏会保存进度并结束服务。

5. 设备、应用及网络：SDK 在同意后的登录、必要服务更新、运行安全与平台操作场景，可能处理设备型号、系统版本、语言、ROM 版本、国家码、应用包名/版本、网络类型/状态、IP、UDID、OAID 等必要标识及运行/诊断信息。具体信息范围与触发机制以所用 SDK 及其公开隐私声明为准，不以取得授权为由收集无关信息。

6. 兼容性和安全：按照平台 SDK 说明，在实现设备兼容性及安全风控所必需的场景，可能读取可用/特定类型传感器的类型列表及与平台服务相关的已安装应用信息。类型列表不等于加速度等传感器实时数值。本游戏自身没有读取传感器实时数值、通讯录、定位、相册、摄像头、麦克风的功能。

7. 客服：您主动电话或邮件联系时，我们在处理问题所需的范围内处理您提供的联系方式、问题描述和材料。请勿发送无关敏感资料。

8. 在线政策：游戏内可离线阅读完整正文。您主动打开“在线原文”时，由系统浏览器访问 GitHub Pages；托管方可能处理网页请求、IP 和访问日志，页面未植入广告、统计或追踪脚本。

五、存储、安全与跨境

本地数据保存在应用私有目录，直至清除、卸载或系统删除；账号认证信息由荣耀平台按其规则保存。平台信息存储、处理期限及行权渠道请查阅其隐私说明；本游戏不自建账号数据库，也不在 APK 中存储开发者 Client Secret。

客服材料在处理及履行必要法定义务所需期限内保留，之后删除或匿名化。我们采取合理的访问控制与保护措施。
