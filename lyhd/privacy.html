《乐园花朵消消》隐私政策

更新及生效日期：2026年10月19日
适用版本：本地游客版 1.0.0（100）

广州刘诚恒科技有限公司（以下简称“我们”）重视您的隐私。本政策说明您使用《乐园花朵消消》（包名：com.match.lyhd.honor）时的信息处理方式。请在使用前完整阅读。

本版本的重要说明：游戏为本地游客体验，不设账号服务器，不包含广告、付费、统计分析、社交分享、云存档或第三方账号 SDK；安装包不申请 Android 系统权限。游戏核心玩法无需联网。普通“游客登录”仅表示进入本地游戏，不构成荣耀账号登录、实名认证或防沉迷认证。

一、我们处理哪些数据

本地游戏数据：关卡解锁记录、星级、最高分、当前关卡及弹珠状态、已选弹珠外观、道具剩余数量和隐私同意状态，用于保存进度、恢复挑战和记住设置。这些数据保存在应用私有目录中，不会由本版本上传至我们或第三方服务器。应用不启用 Android 系统自动备份。

我们不主动收集：姓名、身份证号、手机号、通讯录、照片、精确或粗略位置、麦克风内容、设备广告标识符、Android ID、已安装应用列表、传感器列表及实时数值。本版本也不生成跨应用跟踪标识。

主动联系：当您通过电话或邮箱向我们反馈问题时，我们仅为回复及处理该次请求而使用您主动提供的联系方式、反馈内容及必要的核验信息。请勿发送与处理问题无关的敏感信息。

二、第三方服务及权限清单

本版本未集成第三方 SDK，未接入荣耀账号、联运、广告、支付、Firebase、AppsFlyer、IronSource 或 Unity 运行时。不申请网络、定位、存储、通讯录、相机、麦克风、安装应用、查询全部应用等 Android 权限。“openid”属于后续可能接入的账号授权范围，当前版本不申请此授权。

点击“在线版”时，将由您设备的外部浏览器打开 GitHub Pages 托管的协议网页。浏览器及托管平台可能为提供网页服务而处理 IP 地址、访问日志等信息，其处理规则由相应服务提供方说明；游戏不会因此取得您的浏览记录。应用内可直接阅读内置全文，无需打开外部网页。

三、同意、拒绝与撤回

首次进入时，我们展示本政策和用户协议入口。您可同意后使用本地存档，也可选择“离线体验”：该模式的游戏状态仅在本次会话内保留，退出后不持久保存，不会上传数据。拒绝非必要信息处理不会导致频繁索取授权。

您可在“花园设置—撤回隐私同意并清除数据”中撤回同意并删除本地游戏数据；也可通过 Android 设置清除应用数据或卸载。撤回同意不影响撤回前基于有效同意进行的处理。

四、存储、安全及保存期限

本地进度保存在当前设备的应用私有目录，直到您主动清除、卸载或设备数据被移除。我们不建立该版本的云端游戏数据库，不主动向境外传输本地进度。请注意，卸载、清除数据或更换设备可能造成进度丢失，当前版本无法从服务器恢复。

我们采用应用沙箱、最少权限和关闭自动备份等措施降低风险。任何系统均无法保证绝对安全；如发现与本游戏有关的信息安全问题，可通过下方联系方式反馈。

五、共享、转让与公开披露

本版本不出售、出租、共享、转让或公开披露本地游戏数据。处理您主动反馈的问题、履行法律义务或依法配合有权机关要求时，仅在必要范围内处理您主动提供的信息，并依法采取保护措施。

六、您的权利及处理渠道

您依法享有知情、决定、查阅、复制、更正、补充、删除、撤回同意及限制处理等权利。本地进度可在游戏中查看，弹珠设置可直接更改；删除及撤回方式见第三节。当前没有注册账号，因此不设在线账号注销流程；清除本地数据即可移除本设备的游客记录。

如需协助，请通过下方邮箱或电话联系。我们将在收到请求后十五个工作日内回复，必要时仅要求与核验该请求有关的最少信息。

七、未成年人保护

适龄提示为 8+。未满十四周岁的用户应在监护人指导下阅读本政策和用户协议。我们不在本版本主动收集儿童个人信息；若通过反馈渠道收到儿童信息，监护人可申请删除。当前游客体验不等同于已完成平台实名认证或防沉迷接入，请合理安排游戏时间。

八、政策更新

若后续接入荣耀账号、联运、实名认证、防沉迷或其他服务，我们将在功能启用前更新具体 SDK 名称、提供方、信息种类、用途、触发时机、权限和政策链接，并依法取得必要同意。不得将本政策作为未接入服务的已接入证明。对影响您权利的实质变化，我们将通过应用内显著提示告知。
