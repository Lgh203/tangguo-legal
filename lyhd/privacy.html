广州刘诚恒科技有限公司（以下简称“我们”）重视您的个人信息。本政策说明《乐园花朵消消》（包名 com.match.lyhd.honor）及其必要的荣耀服务如何处理信息。请在首次使用前阅读。

本次版本变更：本版本接入荣耀游戏联运 SDK 2.0.28.301，用于荣耀账号登录、实名认证/防沉迷、角色信息上报和退出引导。该 SDK 内含账号及支付组件，并依赖荣耀数据分析、标识符和安全基础组件。游戏没有广告展示、商品、充值或付费入口，不主动调用支付接口。不能将上一游客版“无 SDK、零权限”的说明用于本版本。

一、信息种类、用途与触发时机

1. 游戏本地记录：关卡进度、星级、分数、花币、弹珠外观、道具、设置及未完成关卡保存在本机私有目录。登录后使用荣耀账号标识的散列值区分本地存档，避免不同账号共用进度。本版本没有自建云存档或用户数据库，不启用系统自动备份。

2. 荣耀登录：在您同意本政策并点击“荣耀账号登录”后，SDK 启动必要服务，可能处理 Open ID、UnionID、登录及认证结果、设备标识符（UDID、Android ID、OAID）、设备型号、操作系统/ROM 版本、语言、国家码及 SIM 国家码、运营商、应用包名/版本、网络类型、IP 和必要运行/安全日志，用于账号识别、兼容性、安全、服务通信和风险控制。SDK 通过网络向提供服务所必要的服务器传输。本游戏不申请头像和昵称授权；不下载或展示您的账号头像，不记录登录 token 到磁盘或日志。SDK 可能返回 UnionID 等基础信息，我们的业务代码只使用 Open ID 的本地散列标识关联存档及角色。

3. 实名认证/防沉迷：在您主动提交或平台要求认证时，由荣耀认证流程处理姓名、身份证号、认证结果和年龄状态。游戏不自建身份证收集表单；收到平台防沉迷退出指令后保存本地进度并退出，不能通过游客入口绕过平台登录或认证。

4. 游戏角色：登录进入游戏、回到前台及关卡/分数等角色信息变化时，上报散列角色标识、固定角色名称“花园玩家”、关卡等级、区服名称、章节和积分，用于荣耀游戏服务。该数据不包含您未授权的头像或昵称。

5. 服务与安全：荣耀组件为网络通信、退出引导、服务更新和安全检测处理必要设备、应用及日志信息。关联启动场景包括拉起荣耀账号进行登录/认证、游戏中心与游戏管家提供浮层服务，以及平台更新/下载服务。SDK 的数据分析依赖用于必要的服务运行和故障排查；游戏不另接第三方营销统计或个性化广告。

6. 联系我们：您主动通过电话、邮箱反馈时，我们仅为处理请求使用您提供的联系方式、问题描述及必要核验信息，请勿提供无关敏感信息。

三、系统权限与应用查询

联网和网络状态用于账号及必要服务通信。官方联运 SDK 还声明前台服务、请求安装应用及荣耀游戏中心/管家/支付服务的专用交互权限，应用查询限于荣耀账号、游戏中心、游戏管家、应用市场等必要包。请求安装应用用于平台服务/游戏升级场景，并不意味着未经系统授权静默安装。我们不主动弹出与当前操作无关的安装授权请求。

本游戏不申请位置、相机、麦克风、通讯录、外部存储、查询全部应用等权限。SDK 授权不等于取得任意数据使用权，不需要的权限不申请，游戏不单独采集实时传感器数据。您可通过 Android 设置管理相关权限；拒绝非必要权限不会影响与该权限无关的功能。

四、同意与撤回

首次使用或政策发生实质变化时，先展示本政策和用户协议。不同意时不启动荣耀服务，仍可阅读协议和联系信息。点击登录前需同意本政策；账号、实名认证和防沉迷是本联运版本进入游戏所需的平台服务，不提供跳过认证的游客模式。

您可通过“设置—撤回隐私同意并退出”撤回同意，游戏将清除当前账号的本地游戏记录并关闭应用；下次进入需重新确认。撤回不影响此前合法处理。游戏内撤回不会注销设备上的荣耀账号；平台账号资料管理方式见第六节。

五、存储、共享与安全

本地进度保存至您清除应用数据、撤回并删除、卸载或设备数据被移除时。必要的荣耀服务信息由荣耀按其政策在境内处理并按实现服务和法定义务所需期限保存；本游戏不另行向境外提供本地进度。我们不出售、出租您的个人信息，只为声明的服务向必要提供方传输，或依法履行有权机关的要求。

我们使用应用沙箱、TLS、安全依赖、最少权限和不记录登录凭证等措施。更换设备、卸载或清除数据可能导致本地进度丢失；当前没有云端恢复功能。

六、您的权利与账号管理

您依法享有知情、决定、查阅、复制、更正、补充、删除、撤回同意及限制处理等权利。可在游戏中查看关卡并修改设置、删除当前账号本地进度。清除本机记录与注销荣耀账号不同；荣耀账号的更正、删除、注销及平台认证资料请求，请通过荣耀账号设置或以上荣耀政策中的服务渠道办理。我们将在核验请求后依法协助涉及本游戏的事项，通常在十五个工作日内回复。

适龄提示为 8+。未满十四周岁用户应在监护人指导下阅读并使用；涉及儿童信息时依法取得监护人同意。平台实名认证/防沉迷由荣耀服务执行，游戏遵从平台返回结果。适龄提示不能代替实名认证，也不表示完成出版审批。

八、政策更新与外部网页

新增功能、SDK 或重要信息处理变化时，我们将在启用前更新政策并依法重新取得同意。应用内置完整正文；点击“在线版”将由外部浏览器打开 GitHub Pages 页面，浏览器和托管平台可能按其自身规则处理网页访问 IP 及日志，游戏不会因此获取您的浏览记录。
