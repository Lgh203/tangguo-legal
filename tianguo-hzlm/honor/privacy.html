一、信息处理目的与场景

本游戏在设备应用存储中保存关卡进度、道具数量、分数、音效及其他游戏设置。Unity 引擎使用触控、设备型号、操作系统版本、屏幕和图形能力等运行信息，用于绘制画面及处理游戏操作；异常可能记录在设备系统日志中。游戏运营方本版本未部署独立账号服务器、云存档或游戏日志上传服务。荣耀平台服务仍需要联网，未部署自有服务器不表示应用完全离线。

在您明确选择同意后，客户端本地记录政策版本及同意时间。荣耀 SDK 完成登录后返回账号标识等结果；本版本仅在当前进程内使用 OpenID 确认登录状态，不保存或展示 SDK 返回的令牌，不主动请求昵称、头像。游戏存档仍为设备本地存档，不是账号云存档。

二、荣耀 SDK 与其他组件

荣耀游戏联运 SDK的运营者为深圳荣耀软件技术有限公司。用于游戏初始化、荣耀账号登录，以及平台配置的实名认证、防沉迷、公告、活动、退出管理。其处理范围可能包括账号标识（OpenID、UnionID）、设备标识符（UDID、AndroidID、OAID）、设备型号、系统/ROM 版本、语言、SIM 卡国家码及运营商信息、应用包名及版本号、网络类型和 IP 地址，以及活动参与情况。涉及实名认证时，姓名和身份证号由荣耀 SDK 的对应流程收集处理，不由本游戏自建页面收集。是否触发这些流程取决于平台配置、设备及用户操作，不将全部字段描述为每次必定采集。

荣耀 SDK 的账号及设备信息、频次与规则以其公开说明和所展示的协议为准。请阅读 荣耀 SDK 隐私声明及数据处理说明。本版本在同意并点击登录后调用 SDK。平台可能唤起荣耀账号或游戏服务应用；本游戏未添加后台自动登录的业务入口。

本 APK 为原游戏恢复渠道版本，包含尚未清理的荣耀广告、支付、统计及标识符兼容代码。当前游戏业务未开放付费商品、支付下单或广告播放入口，旧广告初始化被停用。保留代码不等于承诺这些组件在任何环境绝不运行；SDK 实际行为需结合对应版本、平台配置和检测结果核对。新增启用功能前将更新本政策并依法征求同意。

Unity 引擎用于本地游戏运行，相关信息见 Unity 玩家隐私说明。
