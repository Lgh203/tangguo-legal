《万宝消消消》隐私政策

更新及生效日期：2026年10月20日 · 适用版本100

本政策适用于版本 100 的本地单机版本。当前游戏不含广告、支付、统计或荣耀账号 SDK，不提供网络账号注册，不向开发者服务器上传游戏数据。游戏无需联网即可使用。未来接入账号 SDK 时，我们将另行更新本政策，并在取得必要同意后启用。

一、我们处理哪些信息

游戏仅在您设备的应用私有存储中保存：隐私同意状态、当前关卡、已解锁关卡。用途为记住您的选择、保存游戏进度。无需提供姓名、手机号、身份证号码或账号密码。我们不读取通讯录、位置、电话状态、设备标识符、传感器列表或已安装应用列表。游戏不采集健康或金融信息。

二、权限及第三方服务

本版本未声明 Android 系统权限，包括联网权限；未集成广告、统计、支付、账号等第三方 SDK。点击“在浏览器查看公开网址”会唤起您自行安装的浏览器；浏览器访问 GitHub Pages 页面时，会按浏览器及 GitHub 自身规则处理必要网络日志（例如 IP 地址）。该访问并非游戏内数据上传。您可以不打开浏览器，直接在游戏内离线阅读全文。

三、信息保存、安全与共享

上述本地记录保存在您的设备中，保留至清除应用数据、卸载游戏或使用游戏内“撤回同意并清除进度”。本版本关闭应用系统备份。我们不出售、出租、共享或向第三方传送本地游戏进度，不将游戏数据传到境外服务器。请保护好设备，防止他人读取或删除本地数据。

四、您的选择和权利

首次启动可先阅读本政策及用户协议，选择同意后继续；不同意可退出。您可在登录页或“玩法与设置”中随时查阅政策，使用“撤回同意并清除进度”删除本地记录并退出，也可通过系统设置清除应用数据或卸载。由于没有网络账号，无需办理账号注销。我们无法恢复已删除的本地进度。

五、未成年人保护

游戏适龄提示为8岁及以上，仅用于玩法难度及内容提示，不替代平台的内容分级、实名认证及防沉迷要求。不满14周岁的儿童应在监护人指导下阅读本政策并取得监护人同意。本版本不索取儿童个人信息。监护人可协助清除游戏数据，或通过下方联系方式向我们反馈问题。
