《星彩消果冻》隐私政策

更新及生效日期：2026年10月19日

欢迎使用广州睿巩科技有限公司（以下简称“我们”）提供的《星彩消果冻》。请在使用前阅读本政策。本政策对应无广告、无支付、无第三方账号登录的本机存档版本 100。

本版本的核心游戏可离线运行。我们不设用户注册后台，不接入广告、统计或账号 SDK，不上传您的游戏存档，也不读取通讯录、定位、相册、设备标识符或已安装应用列表。

一、我们处理哪些信息

游戏在设备内部保存关卡进度、体力、道具、分数、音效开关及隐私同意状态。这些信息用于恢复进度和记住设置，仅保存在应用私有目录。我们没有服务器接收这些数据。当前关卡未结算的临时状态可能不会保存。

本版本的“本机玩家”仅表示设备上的本地存档入口，不创建网络账号，不提供荣耀账号登录或实名认证服务。

二、权限与网络

应用仅声明 Android 网络访问权限 INTERNET，用于后续经更新告知的网络文档功能；不申请定位、电话状态、存储、安装应用、悬浮窗等权限。INTERNET 为普通权限，不会弹出运行时授权框。openid 是未来账号服务的授权范围，与 Android 系统权限不同，当前版本不申请 openid。

应用内的政策和协议采用随包文档，可离线阅读。您在浏览器主动访问 GitHub Pages 公开政策网址时，网站托管服务 GitHub 可能处理访问 IP、请求时间、浏览器信息等网络日志。该访问不上传游戏存档。有关托管方处理方式，请参阅 GitHub 隐私声明。

三、第三方组件与共享

使用 Cocos Creator 2.4.15 引擎在本地渲染、播放音效及保存进度。该版本未接入广告 SDK、支付 SDK、荣耀账号/联运 SDK 或分析统计 SDK。我们不出售个人信息，不向第三方提供您的游戏存档。未来接入账号或其他服务时，将先更新政策和第三方清单，再取得必要同意。

四、存储期限与安全

本地数据保留到您主动清除、卸载应用或系统删除应用数据时。我们通过应用私有目录限制其他普通应用直接访问，关闭系统备份。请勿将此视为绝对安全保证；设备故障、系统重置或卸载可能造成进度丢失。

五、您的权利与操作路径

可在游戏右上角“设置”查看政策和协议。可通过“设置 → 清除本机存档”删除进度与同意状态，也可使用系统“应用信息 → 存储 → 清除数据”或卸载应用。清除操作不可恢复。返回本机登录页后可选择退出；如需撤回已保存的同意，请清除应用数据并停止使用。

当前无网络账号，因此无需申请账号注销。您可通过下方邮箱提出查阅、更正、删除或投诉请求；我们将在收到请求后十五个工作日内答复。由于存档仅在设备本地，我们无法远程调取或恢复存档。

六、未成年人保护

未成年人应在监护人指导下阅读本政策并合理安排游戏时间。未满十四周岁的儿童应取得监护人同意。我们不主动收集儿童个人信息。监护人如认为儿童信息被不当处理，可通过下方方式联系我们。

七、政策更新

如信息处理目的、方式或范围发生重大变化，我们将通过应用更新和显著提示重新告知，依法取得必要同意。政策更新不会使本地离线存档自动变成联网账号。
