《画线连连闯》隐私政策

更新及生效日期：2026年10月17日 · 版本 2026-10-17-honor-v2

请先阅读：本政策适用于《画线连连闯》（com.puzzle.xllc.honor）。本版接入荣耀游戏联运 SDK 的账号、实名认证、防沉迷、角色上报及退出引导功能。只有在您同意本政策并主动点击“荣耀账号登录”后才启动荣耀服务；登录成功后进入游戏。本版没有广告展示、充值或付费功能。

一、我们处理的数据与用途

本机游戏数据：关卡、金币、成长等级、教程状态、声音和振动设置保存在设备应用存储中，用于继续游戏。它们不是云存档；不同账号在同一设备使用同一份本机进度，清除数据或卸载可能丢失记录。政策同意版本也仅在本机保存。

荣耀账号：主动登录时，荣耀 SDK 将通过网络处理账号标识（Open ID、UnionID）、登录凭据及认证结果。本游戏仅在运行内存中使用 Open ID 生成去标识化角色编号，不把原始账号标识或登录 token 打入游戏日志，不自行存储密码，不申请头像、昵称授权。没有自建账号或身份校验服务器；登录状态以荣耀 SDK 的成功回调为准。

实名认证与防沉迷：需要认证时，由荣耀服务处理您主动提交的姓名、身份证号码及认证结果，用于身份核验、年龄判断与防沉迷。本游戏不自行填写、保存身份证信息；收到平台限制或退出指令后停止游戏，不能用游客入口绕过验证。

设备、网络与平台服务：荣耀 SDK 及其必要依赖可能处理设备型号、操作系统版本、语言、ROM 版本、国家码、运营商、包名、版本、网络类型、IP、OAID、UDID、Android ID、系统与应用运行信息，以及平台活动或优惠券相关信息，用于账号及服务可用性、网络安全、兼容性、风险控制、服务升级和平台运营。不同系统、设备、SDK 功能和平台配置下实际字段可能不同，具体范围见下方荣耀官方声明。本游戏不把“不申请头像昵称”等同于 SDK 只处理 Open ID。

角色信息：登录进入游戏和关卡等级变化时，上报去标识化角色编号、固定角色名称“闯关玩家”、关卡等级、区服及章节，用于荣耀联运角色服务。没有真实姓名角色昵称功能，不上报与角色服务无关的私人文件。

联系我们：如您主动发送邮件或来电，我们处理您提供的联系方式、问题及必要核验资料，用于答复和处理请求。请不要发送不必要的身份证件或其他敏感资料。

三、权限、关联启动及调用时机

网络访问（INTERNET）和网络状态（ACCESS_NETWORK_STATE）用于荣耀登录、实名、防沉迷、角色及平台服务，以及主动打开在线文档。振动（VIBRATE）用于命中反馈，可在设置关闭。荣耀 SDK 声明的前台服务（FOREGROUND_SERVICE）与请求安装（REQUEST_INSTALL_PACKAGES）用于平台服务及必要升级/安装流程；只有您触发相应流程时才由系统确认安装，不代表静默安装。荣耀提供方访问权限用于与账号、游戏中心及游戏管家交换必要服务状态。

本游戏不申请摄像头、麦克风、位置、通讯录、短信或广泛文件读取权限，也不自行采集传感器实时数值或完整已安装应用列表。为判断荣耀账号、应用市场、游戏中心、游戏管家等必要服务是否可用，SDK 可查询这些指定软件，并在登录、平台浮层、升级等必要场景关联启动相应服务。不会在用户未同意前初始化荣耀 SDK，不设置自启动广播或无关的后台启动入口。

四、存储、共享与安全

本机进度和同意记录保存在当前设备，直到您清除或卸载（实际删除范围也受系统备份设置影响）。我们不将存档上传至自建服务器。荣耀处理的数据按照其官方声明保存在中国境内：登录数据在注销荣耀账号时处理，实名认证数据按其声明期限保存，风险控制和服务数据按对应目的期限保存；详见官方声明的分类期限。我们不会出售个人信息，向提供相应服务所必要的荣耀处理方传输数据。

GitHub Pages 使用全球基础设施；主动访问在线原文时，网页请求信息可能在其境外设施处理，应用也提供无需联网的随包文本。我们通过应用私有存储、最小必要处理和安全传输降低风险，但不承诺绝对无风险。

五、您的权利与退出方式

设置提供隐私政策、用户协议、清除本机游戏数据及撤回隐私同意入口。清除进度前会再次确认；撤回同意后保存进度并退出，重新启动需要重新阅读并同意，不能在已撤回后继续运行荣耀会话。退出游戏会在荣耀服务已启动时调用官方退出引导，由平台回调决定继续或退出。

荣耀账号由荣耀管理，本游戏不提供删除整个荣耀账号的操作。您可在荣耀账号服务中管理或注销账号，或通过荣耀隐私声明中的渠道提出请求；本机游戏数据可单独清除。对本游戏处理的信息，您可通过以下联系方式申请查阅、复制、更正、删除、撤回或限制处理等权利。我们核验必要身份后依法处理，通常十五个工作日内答复；法律另有要求的按其规定执行。

六、未成年人保护

未成年人应由监护人指导阅读本政策及用户协议，未满十四周岁用户应取得监护人同意。按荣耀实名认证及防沉迷流程提供服务，并执行平台限制或强制退出回调。请合理安排游戏时间，监护人可协助管理数据及提出权利请求。
