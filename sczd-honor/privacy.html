《蛇蛇拆阵大师》隐私政策

更新及生效日期：2026年10月18日 · 适用版本：100（荣耀联运版）

广州钦瑢科技有限公司（以下简称“我们”）是本游戏的运营主体。请在同意并开始使用前阅读本政策。不满14周岁的用户，请由监护人阅读并同意。

重要提示：本游戏无广告、无付费购买。荣耀游戏服务 SDK 在您同意本政策后、主动登录时启动，用于账号登录、实名认证、防沉迷、角色上报及官方退出引导。拒绝同意可退出。进度和皮肤主要保存在本机；登录不代表提供云存档。

一、我们处理的信息与目的

我们在应用私有目录保存金币、宝石、皮肤、天赋、已解锁关卡、战绩、签到日期、声音设置和隐私同意记录，用于继续游戏及记住选择。游戏向荣耀上报必要的角色标识、默认角色名、等级和章节，用于平台联运及防沉迷服务。我们不自建收集上述信息的业务服务器。

主动联系开发者时，我们会处理您提供的联系方式及问题描述，用于答复咨询。请勿提供无关的敏感信息。

二、第三方 SDK 清单

荣耀游戏服务 SDK（含荣耀账号及退出服务），版本 2.0.28.301；提供方：深圳荣耀软件技术有限公司。目的：账号登录、实名认证、防沉迷、角色上报、游戏更新及退出引导。信息类型：账号 Open ID；设备标识 UDID、设备型号、操作系统版本、语言、ROM版本、国家码；应用包名、版本号、网络类型；您向荣耀实名认证页面主动提交的姓名及身份证号。实名认证信息由荣耀服务处理，本游戏不保存身份证号。具体处理以荣耀服务页面说明为准。

频次及时机：您同意后主动启动登录、使用实名认证或联运活动、角色信息变化、游戏退出时，按服务所需进行处理。不以静默或后台持续收集作为游戏功能。我们不申请昵称和头像授权（setNeedProfile=false），不使用信息进行个性化广告推荐。SDK 可能为拉起荣耀账号、游戏中心或游戏管家使用应用间通信。

荣耀隐私声明：荣耀游戏服务隐私声明；荣耀 SDK 隐私说明。SDK 的网络、安全、标识、统计及支付基础组件随联运 SDK 一并分发；其中 hianalytics 统计基础组件用于荣耀服务运行质量监测，其信息处理以荣耀 SDK 隐私声明为准，不用于本游戏广告推荐；本游戏未开通付费商品，也不调用支付接口。

Unity 运行时；提供方：Unity Technologies。用于游戏图形、音效、触控及本地存档。未启用 Unity 广告、云分析和云诊断。Unity 玩家隐私说明。

三、系统权限与网络

应用使用网络访问、网络和 Wi-Fi 状态权限以连接荣耀服务及判断连接状态。联运 SDK 随附前台服务、请求安装应用及荣耀服务组件通信权限；请求安装权限仅在用户主动同意官方更新或账号服务安装流程并由系统授权时使用，不静默安装应用。不申请电话、联系人、位置、相机、麦克风或共享媒体读取权限。Open ID 属于账号授权信息，不能代替以上 Android 权限说明。

隐私政策与用户协议全文内置，可离线打开；第三方网站及荣耀账号登录需要网络。

四、保存、删除与安全

本地进度保存至您清除游戏进度、清除应用数据或卸载为止。卸载或更换设备可能丢失进度。荣耀处理的信息由荣耀按其政策规定保存和保护，我们无法替代荣耀删除账号。您的咨询记录在处理所需期限内保存，处理完成后依法删除或匿名化，法律另有要求除外。我们采取应用私有存储、HTTPS 网络通信和最小必要授权等措施保护信息。

五、您的权利与撤回同意

您可在登录页“隐私与数据管理”及游戏顶部“隐私”入口阅读政策。可撤回同意并退出；下次启动需重新确认。撤回不影响撤回前基于同意进行的处理。可通过游戏设置重置游戏进度，或系统设置清除本应用全部数据。注销荣耀账号或管理荣耀授权，请通过荣耀账号中心办理；本游戏不另行建立服务器账号。

查阅、复制、更正、删除信息及其他个人信息请求，可通过下方联系方式提出。我们将在核验请求及处理范围后15个工作日内答复；涉及荣耀服务的信息，将指引您向相应服务提供方行使权利。

六、未成年人保护

本游戏建议8岁及以上用户使用，未成年人应在监护人指导下使用。不满14周岁用户的监护人可联系我们查阅、更正、删除其信息。游戏通过荣耀官方服务执行实名认证和防沉迷，验证失败或收到平台防沉迷退出指令时停止游戏，不提供绕过实名或防沉迷的入口。

七、共享、境外与变更

我们不出售个人信息，不向广告平台共享游戏信息。提供荣耀服务所需信息由荣耀按其政策处理；本游戏不主动将个人信息传输至境外。因法律要求或其他服务需要处理信息时，我们会依法履行告知、同意等义务。政策重大变化将在应用内提示，需要重新同意时在同意后启用相关处理。
