《奇笔画线大挑战》隐私政策

更新及生效日期：2026年10月20日 · 无广告离线版本100

广州德诺南传媒有限公司（以下简称“我们”）为《奇笔画线大挑战》的运营主体。本政策适用于包名 com.puzzle.qbhx.honor、版本 100 的无广告离线版本。请在首次使用前阅读本政策。

核心说明：本版本无需注册账号，采用离线游客模式；不接入广告、支付、统计、荣耀账号或游戏联运 SDK；不向我们的服务器上传个人信息；不申请定位、相机、麦克风、通讯录、电话、已安装应用列表或共享存储访问权限。

一、我们如何处理信息

为实现游戏进度、关卡、金币、已解锁内容、界面偏好和协议选择的保存，应用在自身私有目录内保存本地数据。上述数据仅保留在本设备，不与真实姓名、手机号或网络账号绑定。我们不为本版本建立服务器用户档案，不进行广告画像或跨应用跟踪。

二、权限与第三方组件

本版本不声明 Android 网络权限和危险权限，不弹出运行时权限申请。不初始化或调用广告、账号登录、支付或第三方统计 SDK 服务，相应 Android SDK 组件已移除。游戏使用本地运行组件：原版恢复实现采用 Unity 引擎，玩法重建实现采用 Android 系统绘图。运行组件仅用于本地画面和玩法，不启用引擎或 SDK 联网分析服务。

查看应用内协议不需要联网。您可主动选择在系统浏览器访问 GitHub Pages 公开协议网页；该操作会打开外部浏览器并访问 GitHub 的服务，网页托管服务可能根据其自身规则处理网络请求信息，我们无法访问其访客日志。GitHub 的处理规则请阅读 GitHub 隐私声明。

三、保存期限、安全与删除

本地游戏数据在您使用期间保留在应用私有目录。您可在应用设置中选择“清除本地存档”，或使用系统“清除应用数据”、卸载应用予以删除。删除或卸载后我们无法找回离线存档；应用不主动进行云端备份。请勿将设备交给未经信任的人使用。

四、共享、转让与公开披露

本离线版本不将游戏存档或个人信息传输给我们或第三方，不出售个人信息，不进行个人信息跨境传输。您主动通过邮件或电话联系我们时，我们仅为答复、核实和处理您的请求使用您主动提供的联系方式及问题内容，不将其用于营销；处理完成后仅在处理纠纷或履行法定义务所必要的期限内保存。

五、您的选择与权利

首次启动时您可阅读、同意或拒绝协议；默认不勾选。拒绝后应用退出。您可随时在游戏设置中再次查看本政策与用户协议；可通过清除本地存档撤回本机保存的协议选择。若需就您主动提交给客服的信息提出查询、更正或删除请求，请通过下方邮箱联系。我们会在核验必要信息后于十五个工作日内答复。

六、未成年人保护

未成年人应在监护人指导下阅读本政策并合理安排游戏时间。我们不主动向儿童收集身份信息。若监护人发现未成年人向客服主动提交了不必要的个人信息，可联系我们申请删除。本离线游客入口不等同于实名或防沉迷认证。

七、政策变更

若后续版本接入荣耀账号、联运或其他需要处理个人信息的功能，我们将先更新政策、列明 SDK 名称、提供方、信息类型、目的与链接，并在适用时重新取得您的同意；本政策不代表这些功能已接入。
