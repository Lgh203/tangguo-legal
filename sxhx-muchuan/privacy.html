《随心画线大闯关》隐私政策

更新及生效日期：2026年10月22日

广州牧川传媒有限公司（以下简称“我们”）重视您的个人信息和隐私。本政策适用于《随心画线大闯关》（包名 com.sxhx.puzzle.honor，版本100）的荣耀联运版本。请在同意前阅读完整正文和《用户协议》。

本次更新：本版本接入荣耀游戏联运 SDK 2.0.28.301，使用其账号登录、实名认证/防沉迷、角色信息上报和退出服务，以及随 SDK 提供的必要基础依赖。它已经不再是此前的纯离线游客版本。仅在您同意本政策后启动 SDK，在您主动登录或使用相应服务时调用相关接口。本游戏没有广告展示、充值或内购功能。

一、我们处理的信息及目的

1. 荣耀账号：您主动点击“荣耀账号登录”后，SDK完成账号登录、必要认证和平台初始化。SDK可能处理 Open ID、UnionID、登录凭证及认证结果；本游戏使用 Open ID 识别游戏角色，登录凭证仅在当前进程内存保存，不记录到日志或公开展示。未主动申请头像、昵称等额外个人资料；不收集荣耀账号密码。未成功登录不进入正式游戏。

2. 实名与防沉迷：在平台要求且您主动进入认证流程时，可能由您向平台提交姓名、身份证件号码等资料，用于身份核验、年龄判断和防沉迷。我们不自行创建身份证信息输入表单或保存原始身份证资料。平台要求退出或限制游戏时，应用按 SDK 回调停止游戏和退出。

3. 基础运行与安全：SDK及必要基础依赖可能处理设备型号、操作系统和ROM版本、语言、国家码、运营商信息、设备标识符（UDID、Android ID、OAID）、IP地址、网络类型、包名和应用版本、运行或错误日志等，用于账号及联运服务、安全风控、运行兼容、更新和故障分析。具体字段与触发行为随对应 SDK 和关联服务实际功能而定；本游戏不将这些信息用于广告展示或个性化推荐。

4. 设备兼容性信息：平台服务在必要兼容和风险检查中可能读取设备可用传感器或特定传感器的类型列表，以及判断荣耀账号、游戏中心、游戏管家等必要组件是否可用的应用信息。我们不自行采集传感器实时测量值，不自行遍历与游戏无关的应用列表。

5. 游戏角色与进度：登录进入游戏及角色关卡等级变化后，通过联运接口上报角色标识、角色名“画线玩家”、角色等级、区服标识、区服名、关卡章节及通关积分，用于平台角色管理和联运服务。关卡解锁、装扮配色和音效设置保存在本机；账号关联键由 Open ID 生成摘要，用于区分本机存档。当前不提供开发者云存档或跨设备恢复。

6. 画线操作与客服：画线路径仅在运行内存中用于移动和碰撞判断，退出当前关卡不保存。您主动电话或邮件联系客服时，我们会收到您自愿提交的联系方式、问题描述和附件，用于处理请求；请勿提供不必要的敏感信息。

三、系统权限及关联启动

网络访问（INTERNET）、网络状态（ACCESS_NETWORK_STATE）和Wi-Fi状态（ACCESS_WIFI_STATE）用于平台登录、认证、角色上报、退出及服务通信。SDK随包声明的应用安装请求（REQUEST_INSTALL_PACKAGES）用于需要更新荣耀基础服务或应用时，在用户主动操作及系统授权后拉起系统安装器，不用于静默安装。SDK可能随包声明前台服务及荣耀平台受保护服务权限，用于相应平台服务；声明不代表本游戏在后台持续运行或已获得所有受保护权限。

本游戏不申请相机、麦克风、通讯录、精确或粗略定位、电话状态、外部存储等危险权限。您可在系统应用设置中查看和管理实际授权。拒绝安装基础服务可能影响相应平台能力；拒绝非必要权限不应影响已可提供的基本玩法。

荣耀账号登录、SDK认证或必要平台操作可能关联启动荣耀账号APP；平台礼包、浮层或资产功能可能关联启动游戏中心、游戏管家等组件。应用自身不设置开机自启动或定时后台唤醒任务，不主动配置后台持续采集。后台或静默信息处理应遵守荣耀 SDK 的政策与设置，我们仅按前台必要服务时机调用接口。

四、存储、安全与保存期限

游戏存档和同意记录保存在您的设备应用私有目录。清除应用数据、卸载或设备故障可能导致本地进度丢失，开发者无法恢复未提供云同步的存档。当前登录凭证仅保存于进程内存，退出后清理。

SDK处理的数据由相应服务提供者依据其政策和适用要求保存；我们不自行设置境外服务器接收游戏资料。客服资料仅保留至问题处理及必要后续处理期限届满，法律另有要求的除外。我们采取合理的访问限制、安全传输和必要保护措施。

五、您的权利、注销及撤回

您可在游戏内查看关卡和装扮；通过系统设置清除本地数据或卸载应用删除存档；在登录页或游戏设置中撤回本政策同意。撤回后清除同意记录并结束当前应用进程，停止本次平台会话；本地游戏存档不会因撤回而自动删除，删除可使用系统清除数据。再次使用需要重新阅读和同意。我们不自建独立于荣耀的用户注册账号。

荣耀账号的查阅、更正、删除、注销等权利可通过荣耀账号服务相应入口及其隐私声明指引行使；涉及本游戏角色或您主动提供给我们的资料，也可通过下方联系方式申请。我们将在必要身份核验后，通常在15个工作日内回复；法律另有规定的从其规定。撤回不影响撤回前基于同意已进行处理的效力。

六、未成年人保护

未成年人应在监护人指导下阅读本政策。我们按平台接口接入实名及防沉迷相关流程，在收到平台退出或限制回调时执行处理，不提供游客绕过认证进入正式游戏的入口。相关后台资质、实名与防沉迷配置由运营主体按渠道要求落实。

七、政策更新与网页访问

新增功能、SDK版本或信息处理发生重要变化时，我们将更新政策并依法重新取得必要同意。当前应用内提供政策和协议的离线正文，不依赖联网阅读；主动点击“在浏览器查看”会由系统浏览器访问 GitHub Pages，托管服务可能处理访问 IP、时间等常规访问日志，见GitHub隐私声明。
