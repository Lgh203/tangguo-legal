《随心画线大闯关》隐私政策

更新及生效日期：2026年10月21日

广州牧川传媒有限公司（以下简称“我们”）重视您的个人信息保护。本政策适用于《随心画线大闯关》（包名 com.sxhx.puzzle.honor）的本地体验版本 100。请阅读后自主决定是否同意。

当前版本说明：游戏提供离线画线闯关功能。未接入广告、支付、荣耀账号、联运、实名认证、第三方统计或云存档 SDK。当前“本地游客”入口仅建立本机资料，并非荣耀登录或实名认证。未配置服务器，不向我们或第三方上传游戏资料。

一、处理的信息与用途

1. 本地昵称：您可选填昵称用于界面展示；不填写可使用默认昵称，无需提供真实姓名、手机号、身份证件或密码。

2. 本地游戏资料：包括已解锁关卡、通关状态、装扮配色、音效设置及隐私同意版本，用于保存进度、显示界面和记住您的选择。通过系统 WebView 的本地存储保存在本机应用私有数据目录。

3. 触摸操作与运行：画线路径在运行时内存中用于角色移动与碰撞判定，不上传；未完成的关卡路线退出后不保存。应用不主动收集设备标识符、位置、通讯录、传感器数据、已安装应用列表、广告标识符或账号标识。

4. 客服：仅在您主动通过电话或邮件联系时，我们会收到您提供的联系方式、问题描述和附件，用于回复与处理请求。请勿发送不必要的敏感个人信息。

二、权限与第三方组件

本地版本未声明网络访问权限，不申请电话、定位、相机、麦克风、通讯录、存储或安装应用等权限。游戏使用 Android 系统 WebView 展示本地页面，不含第三方广告或数据采集 SDK。系统组件自身的数据处理由其提供方依照相应政策负责。

政策正文随安装包提供，可离线打开；您主动点击“在浏览器查看”时，会由系统浏览器访问 GitHub Pages。该网站托管服务可能根据其规则处理访问 IP、请求时间等常规访问日志。详情见 GitHub 隐私声明。浏览器访问不等于本游戏读取或上传本地存档。

三、共享、转让和公开披露

本地版本不主动共享、出售、转让或公开披露您的本地游戏资料。对主动提供的客服资料，我们仅在处理请求所需范围内使用；法律法规要求的处理依照法定程序执行。

四、保存、删除与安全

本地资料存储在您的设备中，不由我们远程保存。您可在游戏“设置与帮助—清除本地资料”、系统应用设置中清除数据，或卸载应用删除。清除、卸载或设备损坏可能导致进度永久丢失，我们无法恢复未上传的存档。

客服资料保留至问题处理完毕及必要的后续处理期限结束；法律法规另有要求的从其规定。我们对所收到的资料限制访问并采取合理保护措施。

五、您的权利与撤回同意

您可在游戏内查看昵称、关卡进度和设置；通过游客入口修改昵称；通过“设置与帮助”清除资料、撤回隐私同意或退出游客入口。退出游客入口不会自动删除存档，删除需使用清除资料功能。撤回同意会清除本地资料并返回首次隐私提示。拒绝首次同意可退出应用。

如需查阅、复制、更正、删除您主动提供的客服资料，或提出隐私投诉，请通过下方联系方式联系我们。我们将在核验必要身份信息后，通常在15个工作日内回复；法律法规另有规定的遵照规定。

六、未成年人保护

未成年人应在监护人指导下阅读本政策并使用游戏。我们不要求填写真实身份资料，不设置付费或广告。本地体验版本尚未提供平台实名认证和防沉迷认证，不宣称已完成相关平台要求。监护人可管理设备使用时间、删除本地资料，或就主动提交的客服信息联系我们。

七、更新与后续服务

如后续接入荣耀账号、联运、实名认证或其他服务，我们会在启用前依据真实 SDK 行为更新信息种类、用途、触发时机、共享方和权限说明，并在依法需要时重新取得您的同意。当前版本不因预留后续开发计划而提前采集这些信息。
