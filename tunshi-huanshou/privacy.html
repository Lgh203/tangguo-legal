《吞噬幻兽王国》隐私政策

更新及生效日期：2026年10月16日 · 文本版本100-20261016

我们重视您的个人信息和隐私。本政策适用于《吞噬幻兽王国》版本100（包名 com.rpg.tungame.honor）的当前单机功能。请在进入游戏前阅读，您可以选择同意或拒绝。

当前版本说明：本版本提供本机进入，不创建在线账号，不接入荣耀账号、联运、广告、支付或统计SDK，不提供联网对战、聊天或云存档。游戏内对手为本地电脑对手。本机进入不代表完成实名认证或荣耀账号登录。

一、信息处理与使用目的

本地游戏数据：您输入的昵称、选择的地图、玩法、外观、音效设置、成长值、成就、最佳成绩、局数和胜场，保存在本设备的应用私有存储中，用于显示角色、恢复设置及保存游戏进度。我们未设置接收这些游戏数据的业务服务器，不主动上传这些数据。请勿在昵称中输入真实姓名、联系方式等敏感信息。

同意记录：本设备保存您是否同意本政策及用户协议、所同意的文本版本，以控制进入流程；撤回同意后清除该记录，返回隐私选择页。

协议网页访问：只有您主动点击在线协议时，应用才通过系统浏览器访问 GitHub Pages。网络通信会向网站托管服务提供方 GitHub 传输 IP 地址、浏览器请求头、访问时间和所请求的网址，这是加载网页所需的技术信息。网页不包含我们添加的广告、追踪脚本、表单或统计代码。GitHub 对其网站访问数据的处理请参阅 GitHub 隐私声明。这项网页访问涉及境外托管服务；您也可以只阅读应用内置的完整协议，不发起网页访问。

主动联系：如果您主动通过电话或电子邮箱联系我们，我们会处理您提供的联系方式、问题内容和必要的核实材料，仅用于答复、处理请求与解决问题；请勿发送无关敏感资料。

三、设备权限

游戏基本玩法不需要通讯录、电话、短信、位置、相机、麦克风、已安装应用列表或共享存储权限，不主动读取广告标识符、传感器列表或实时传感器数据。在线协议由您选择通过系统浏览器打开，浏览器的网络访问由其自身管理；本游戏本身不申请网络访问权限。您可以始终阅读内置文本。

四、保存期限、安全与删除

游戏数据保存在您的设备中，直至您在游戏内清除本地数据、通过系统清除应用数据或卸载。系统或设备的备份行为由您的系统设置管理，本游戏不提供云备份。我们采用系统应用私有存储保护本地记录。客户联系资料仅在处理请求及履行法定义务所必需期限内保留，目的完成后依法删除或匿名化。

五、您的权利与操作入口

您可以在主页“隐私与协议”随时查阅本政策、用户协议和联系方式；在主页编辑昵称；在隐私中心选择“撤回同意”，结束本次本机使用并回到首次选择页。撤回不影响撤回前基于同意的处理。“清除本地数据”经二次确认后删除昵称、进度、设置及同意记录，该操作无法恢复。当前无在线账号，故不存在服务器账号注销；本地资料可按上述方式删除。您也可联系我们申请查阅、复制、更正、删除或提出投诉，我们将在15个工作日内答复；法律另有期限要求的从其规定。
