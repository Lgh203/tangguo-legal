《一笔连连画线》隐私政策

更新及生效日期：2026年10月18日

广州徽宇润传媒有限公司（以下简称“我们”）运营《一笔连连画线》（包名 com.puzzle.bllh.honor）。本政策说明当前版本处理信息的方式。

当前适用范围：本政策对应版本 100 的离线体验构建。当前未接入荣耀账号、联运、广告、支付或第三方统计服务。若正式发行版本接入账号、实名认证、防沉迷或平台 SDK，我们将在启用前更新本政策、SDK 清单和应用内告知，并在需要时重新取得同意。此处不表示相关平台服务已经接入。

一、我们处理哪些信息

本地游戏数据：隐私同意状态、当前关卡、通关记录及游戏进度保存在设备的应用私有存储中，用于继续游戏。当前无注册、云存档或用户资料上传功能，不要求填写手机号、身份证号码、通讯录、位置或相册资料。

运行信息：Android 系统和游戏运行时需要在本机处理触摸操作、画面尺寸、设备图形能力、系统版本及运行状态，用于显示画面、执行关卡和兼容性处理。我们未在本构建中设置自有分析服务器或主动上传日志功能。

查看在线文档：当您主动打开在线隐私政策或用户协议时，应用内浏览器通过 HTTPS 访问 GitHub Pages。该网络请求会将 IP 地址、浏览器基本请求头等必要网络信息提供给托管服务，以返回文档。我们未在页面中加入广告、分析脚本或追踪 Cookie。离线或网络加载失败时，应用提供本地文档副本。

主动联系：您通过电话或邮件联系我们时，您主动提供的联系方式、问题描述及附件可能被用于处理您的请求。请避免发送无关敏感信息。

二、第三方组件与共享

组件或服务用途处理方式
Android WebView显示协议文档仅在您主动查看协议时加载指定页面；禁用页面 JavaScript，提供本地文档备用
GitHub Pages（GitHub, Inc.）托管公开协议页面按用户请求提供文档，可能处理必要的访问网络信息。GitHub 隐私声明

当前未集成广告、支付、荣耀账号或荣耀联运 SDK。我们不出售您的个人信息。除依法应当配合的情形外，不向其他主体提供您的本地存档。

三、权限说明

应用声明普通网络权限 INTERNET，用于主动查看在线协议。该权限不是系统弹窗授权。当前不申请定位、相机、麦克风、通讯录、读写共享存储或读取手机状态等运行时权限。后台账号服务的 openid 授权范围与 Android 系统权限不同；当前离线构建没有申请 openid。

四、存储、安全与期限

关卡和同意状态保存在设备本地，直至您清除数据或卸载应用。清除数据、卸载或更换设备可能造成进度丢失。应用关闭系统云备份，协议采用 HTTPS。我们采用应用私有存储、最小化信息处理等方式保护数据。主动联系产生的材料仅保留处理请求及履行法定义务所需时间。在线协议由 GitHub Pages 托管，访问该页面涉及其全球网络基础设施；当前游戏存档不因此上传。

五、您的权利与操作方式

您可以在“设置与隐私”中查看协议、清除关卡进度、撤回隐私同意并退出。全部应用本地数据可通过系统“设置—应用—存储—清除数据”删除。当前没有服务器账号，因此无需注销服务器账号。您也可以通过下方联系方式请求知情、查阅、复制、更正、删除、撤回同意、限制处理或投诉；我们会在核验必要身份后依法答复，通常在十五个工作日内处理。

六、未成年人保护

适龄提示暂定为 8+，正式评级以平台核定为准。未成年人应在监护人指导下阅读协议并使用游戏。不满十四周岁的未成年人如需提供个人信息，应先取得监护人同意。当前离线体验构建未完成平台实名认证、防沉迷接入，不代表正式发行资质或平台审核已经具备。正式发行前应按适用法律及平台要求完成相关服务。

七、政策更新与联系我们

服务、信息处理方式发生实质变化时，我们会更新本政策并在游戏中显著提示。需另行取得同意的，在同意前不启用相关处理。
